# Kamal Singh — Senior Android & AI Mobile Developer Portfolio

A responsive GitHub Pages-ready portfolio using the reference portfolio's navy / pink / peach visual direction.

## Hero phone images

The hero section no longer uses the KS/code-card artwork. It uses three replaceable image files:

- `assets/hero-work.png` — work / field-service mobile app
- `assets/hero-utility.png` — Android utility / workspace app
- `assets/hero-ecommerce.png` — iOS-style ecommerce app

Replace these files with your own screenshots or phone mockup renders **using the same filenames**. PNG, JPG or WebP content can be converted/saved with the same `.png` filename, or update the three paths in `index.html`.

Recommended source images: portrait phone screenshots around 9:16. The website automatically applies the phone framing, rotation and responsive layout.

## Run locally

Open `index.html` in a browser. No build system is required.

## Publish to GitHub Pages

1. Create a GitHub repository.
2. Upload all files and folders to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from branch → main → / (root)**.
5. Save and open the generated Pages URL.
